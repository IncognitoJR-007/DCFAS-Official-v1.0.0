# DCFAS - Decentralized Cybersecurity Framework for Autonomous Systems

**Original Concept by Rahul Jebin Raju**  
**Co-developed with Santo Cyriac**

This is the official repository for the DCFAS concept. It includes high-level documentation and licensing to protect the original idea.

## Overview
DCFAS (Decentralized Cybersecurity Framework for Autonomous Systems) is a blockchain, AI, and edge computing-based framework designed to protect autonomous systems in real-time.

Refer to `DCFAS_Whitepaper.md` for a detailed explanation.

This concept is protected and published under the Digital Object Identifier (DOI): [10.5281/zenodo.15332348](https://doi.org/10.5281/zenodo.15332348).
